Deli Menu Sample

Files:
- board1.html = breakfast + omelets/cold sandwiches
- board2.html = hot sandwiches + burgers/sides
- board3.html = combo meals + specials
- menu.css = shared styling for all 3 boards

How to preview:
1. Open board1.html in a browser.
2. Use the small bottom-right links to switch boards.
3. Press F11 on Windows or use browser full-screen mode to test a TV-style display.

For a real TV:
- Each TV can open one board page full-screen.
- Example:
  TV 1: board1.html
  TV 2: board2.html
  TV 3: board3.html

The menu text/prices are sample placeholders and should be replaced with the real deli menu.
